## 1. 产品定位

Velora 是一个**独立 Android GPS 限速巡航/测速仪**，不是导航地图的替代品，也不是赛车/性能测试工具。

目标用户：日常开车、希望在不看导航的情况下，快速知道“这段路限速多少、前方有没有测速、前方路口能不能走”的驾驶者。

产品原则：

- 只关心**当前/面前**，不展示下一段路/下下段路（用户明确要求）。
- 克制、无框无阴影、文字少；深/浅跟随系统，不手动切主题。
- 没有确定数据就隐藏，不显示“限速未知”之类的噪音。
- 安全语义优先：未知限速不判超速；无电子眼不标红。

## 2. 核心功能与预期行为

### 2.1 速度与限速

- 显示当前车速（仅在有实时、卫星来源、精度合格的速度时显示）。
- 显示当前道路限速（仅在有当前、link 级定位时显示）。
- **限速对象三分（用户已确认）**：当前道路限速、前方摄像头限速、区间限速是独立概念。道路限速未知时不用摄像头限速填充；两者不同时，限速牌显示道路值，电子眼胶囊显示该摄像头值；区间平均用区间自己的限速。未知就隐藏，不为“始终有数字”混用数据。
- 超速状态：
  - 未知限速：不判超速、不显示“未知”。
  - 无电子眼：按用户确认口径，**只显示限速，不标红**。
  - 有电子眼（800m 内）：低于阈值标红不闪，超过阈值红闪；阈值默认 10%，可设 0/5/10/15/20%。
- 区间测速：
  - 进入前显示“进入区间测速 + 距离”；
  - 区间内显示平均速度圆盘、剩余距离；**有速度样本的时长占比低于 70% 时隐藏平均圆盘**，避免把缺测按 0 算出的偏低平均值展示；
  - 区间内瞬时超速只红不闪；平均超速按阈值红/闪；
  - 结束显示“区间测速结束 + 剩余距离”。

### 2.2 电子眼

- 只在**前方 800m 内**且是测速类电子眼时显示胶囊；
- 胶囊包含类型、距离、限速（有则显示，且必须来自该摄像头自身）；
- 无测速相机时隐藏；
- 区间起点/终点相机参与区间状态机，不只做普通胶囊。

### 2.3 红绿灯

- 巡航态：使用 `static_lamp_search + dynamic_lamp_search`（B 方案），不依赖 `probe_lamp`/鹰眼；
- 能返回多方向（直行/左转/右转/其他）时，分别显示方向 + 灯色 + 倒计时；
- 显示范围上限 300m；实际首次出现距离取决于百度 `static_lamp_search` 的绑路返回，不保证固定 300m；
- 导航态：另一条链路，`IBNRouteGuideManager.TrafficLightListener` 驱动 HUD 胶囊；**导航红绿灯是否交付取决于 SDK/数据覆盖**，不能与巡航链路混为一谈。

### 2.4 车道

- 巡航态：需要百度车信 `lane_arrow`；百度明确为商业收费，用户已决定不再讨论/不采购；**巡航车道不显示是外部能力缺失，不是解析漏读**。
- 导航态：使用百度 Navi SDK 的 `BNavLineItem.resName` → `LaneDrawableMapper`，仅“可用 drawable 方向”，不是结构化车道；推荐以 `_bright` 为准，`_gray` 不推荐。
- 车道组合图标必须与解析出的方向集合一致；2.9.0 起有纯函数 + 单测锁定。

### 2.5 地图

- 底图是**百度地图 SDK 9.0.2 原生地图**，不是自研地图；无 AK/SDK 不可用时才用 `MapBackdrop` 占位/静态图降级。
- 主页角落小地图与展开地图是**同一个 TextureMapView** 的缩放/位移，不重建、不闪。
- 手势：单指平移、双指缩放/旋转、双击放大；禁用俯仰；不显示指南针/3D 建筑/路况。
- 跟随：仅在定位 GOOD 时持续跟随；网络定位不追；死区 `max(20m, 精度×0.8)`。
- 归中：回中心并复位默认比例尺；收起地图只回中心、保持当前缩放。
- 搜索预览：路线 fit 使用 view 尺寸（扣 28dp 边距），不是 120×120 像素方框。

### 2.6 搜索与导航

- 搜索在展开地图内，不另开导航页；顶部搜索框。
- 搜索并行：附近 `searchNearby`（5km、距离升序、20/页）+ 全国 `requestSuggestion`（`citylimit(false)`），按 uid 合并去重，上限 30，2.5s 超时兜底；**排序按相关度分层（完全匹配 > 包含完整查询 > 查询包含名称 > 类别/模糊），层内距离优先**（Q-21/O04）。
- 历史保存“选中的地点”（非关键词），最多 10 条。
- 多方案算路、方案切换、开始/退出导航。
- 导航宿主：`ADD_MAP=false`，百度导航只跑算路/引导，我们自己的 `TextureMapView` 保留；`NaviGuideHost` 把引导页放在地图下方。
- 导航 HUD：转向卡、车道胶囊、速度/限速、ETA、总览/退出；默认驾驶视角（`setStartByFullView(false)`）。
- 导航相机：导航中相机归百度引擎；我们的相机写入被 `navActive` 门控；onStart 后 1.2s 写一次 `newLatLngZoom(车,17.5)`，不连续写。
- 导航中单指拖动：**当前架构不支持**（`ADD_MAP=false` + 外部地图 + 引擎独占相机），这是已知边界，不是待修开关；独立导航页方案（2.9.3/2.10.0）已回退/留档。
- 退出导航：`stop()` 无条件清理 + `MapSceneController.restoreCruiseScene(...)`（pre-destroy/post-destroy/600ms verify），复位图层模式/路线层/终点图钉/2D/浅色/车标。
- 连续导航：退出导航但不退出 App 后，再次搜索/导航应保持与第一次同等的流畅度；**2.9.2 真机不满足**，第二次导航严重卡顿，需重启 App 才恢复（NAV-09）。
- 导航日夜：设置「白天/夜间/跟随系统」，默认白天；进入导航前、onCreate 后、onStart 后各应用一次；退出复位巡航浅色。

### 2.7 定位可用性

- 多源：`fused`（API 31+）、`gps`、`network`；按 tier → 精度 → 新鲜度选择，带 sticky 防抖。
- 三级：
  - `NONE`：不显示地图；
  - `APPROXIMATE`：仅可显示地图，不能显示限速/车道/电子眼/红绿灯；
  - `GOOD`：可显示道路数据；速度还要求 GPS/FUSED、实时、精度合格。
  - **未报告 accuracy 的定位一律 APPROXIMATE**，不得当成 GOOD（Q-28）。
- 不渲染“定位未知”文案；用“少显示/不显示”表达状态。

### 2.8 设置与语音

- 超速阈值、超速提示音、导航语音播报、保持屏幕常亮、导航地图日夜。
- 设置首页数据服务收敛为一张「数据服务与密钥」入口，副标题概括 HTTP/超视距/红绿灯状态；二级页只显示服务端 AK、Android 应用端 AK、MiMo Key 三项配置和三项服务状态。服务端 SK 从 UI 隐藏但底层兼容字段保留。
- 二级页在 Android 应用端 AK 下显示本包真实 SHA-1 与包名，并提供一键复制；填写说明放在“修改”弹窗内。
- 值存入加密本地存储并脱敏显示，`local.properties` 作为编译期回退。
- TTS：小米 MiMo 直连（无网关）；导航播报受开关控制。**导航切后台或锁屏后仍继续播报**（2026-11-20 用户确认）；退出导航停止当前播报。
- 播报节点：转向按 1000/500/300/100/50 米固定节点各播一次；道路/转向变化才重播；到达、偏航立即播报（Q-27）。
- 设置 → 数据服务与密钥 提供“恢复内置”，清除本机保存值并回退构建内置值；地图 AK 修改后需重启 App 生效。
- 服务端 AK 为空时不发起 Horizon/HTTP/lamp 请求；鉴权失败或高级服务到期时进入长退避并在设置页显示“未开通或已过期”，不影响基础车速表、地图和导航。
- Debug 构建有：超视距路测诊断、导航诊断/导出日志。

### 2.9 诊断

- `NavTrace` 写 `nav-trace.log`（导航生命周期、心跳、场景、相机、FIT、SEARCH、NAVI、CALLBACK）。
- Debug 页面：设置 → 诊断（debug）→「超视距路测诊断」/「导航诊断 / 导出日志」。
- `NavDiagActivity` 收集 `nav-trace.log`、`crash.log`、`horizon-diag.log`、`ApplicationExitInfo`，可系统分享。

### 2.10 性能测试（零百加速）

- **唯一入口**：设置 → 性能测试 → 零百加速；独立 `AccelActivity`，主页/地图/导航/HUD 不新增按钮、浮层或状态。
- 仅测试 **0–100 km/h** 静止起步；成绩卡显示 0–60、0–100 与历史最佳。
- 只读订阅 App 现有位置/速度流；不请求百度、不消耗配额、不启动新的定位会话。
- 复用旧零百项目的静止 2s、0.5 km/h 插值起步、终点确认、10 km/h 分段、质量分级与本地 SQLite 记录；算法位于 `feature/accel/core`。
- 加速度计辅助是可选开关（默认关闭，持久化）；只在 `AccelActivity` 前台且存在准备/测试会话时注册，退出或退后台立即注销；候选必须由 GNSS 速度确认，不参与终点判定，不把传感器值当成绩。无 GPS/信号弱时只显示等待/无效，不伪造时间。
- 性能测试页强制使用 Velora 浅色体系；深色系统下也不切换成赛车仪表盘；顶部只保留返回和克制的辅助开关，赛事/模式文字不堆叠。

## 4. 非目标 / 明确不做

- 不做自研地图引擎/自定义瓦片；底图完全由百度 SDK 渲染。
- 不做离线地图、室内图、3D 建筑、地图原生路况图层。
- 不做导航中的独立 NavActivity（2.9.3/2.10.0 实验已回退/留档），除非重新立项。
- 不在没有车信授权的情况下承诺巡航车道。
- 不用自有后端转发位置/道路数据（App 直连百度；backend 仅历史资产）。
- 不显示“限速未知”等文案；不展示下一段路/下下段路。
- 不用百度默认导航 UI 替代自研 HUD（除非回退 A，需用户确认）。

## 5. 2.9.4 需要特别区分的“需求 vs 实现选择”

- “导航日夜默认白天”和“巡航底图恒浅色”是 **2.9.2 实现选择**，不是用户最终裁决；见 OPEN_QUESTIONS。
- “导航地图红绿灯原生图标”已真机确认**没有**；2.9.4 接受“无原生红绿灯”，不再写成待验证。
- “只显主路线”已确认为 SDK JNI 缺失；调用已移除，不再修补。
- “导航中单指拖动”是 **架构边界**，不是遗漏的开关；当前不修。
- “巡航车道”是 **商业收费/授权阻塞**，用户不再讨论；不要写成“已修复”或“等待技术修复”。
- “个性化地图”未排期，因为用户认可当前样式；不要自行开始重绘。
- 2.9.4 起开发暂告一段落；仅凭实车道路日志重启道路项，不写成“放弃导航”。
